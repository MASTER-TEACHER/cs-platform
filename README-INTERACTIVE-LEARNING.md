# Interactive Learning Engine

Adds a step-based lesson experience with browser text-to-speech audio, saved progress, guided practice, checkpoints, exam questions, reflection and XP completion.

## Install

Copy the folders into the project root. Replace the listed existing files, merge the Firestore rule block, clear `.next`, and run `npm run build`.

## Test

Open `/learn/binary?lesson=binary-intro`, move through every step, test Play/Pause/Stop, answer practice and checkpoint questions, write an exam response, add a reflection, complete the lesson, then revisit to confirm progress restoration.
