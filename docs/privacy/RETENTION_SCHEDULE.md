# CS Master Retention Schedule

**Important:** Final contractual periods should be agreed with legal/data-protection review and, for school-directed records, aligned with school instructions.

| Record | Working retention rule | Disposal |
|---|---|---|
| Active account profile | while account is active | delete/anonymise after closure subject to exceptions |
| School membership | active membership + offboarding/audit window | delete/anonymise or retain minimal audit record |
| Class/assignment records | while educationally required by school | delete/anonymise on school instruction/offboarding |
| Quiz/programming/exam results | while needed for learning/assessment evidence | delete/anonymise per school/account retention |
| Exam integrity incidents | assessment life + short dispute/review window | delete with associated assessment where appropriate |
| AI transient provider data | provider/configuration-dependent; minimise input | rely on contracted provider deletion plus local minimisation |
| Support/feedback reports | until resolved + limited operational audit period | delete/anonymise |
| Privacy-rights case log | keep sufficient accountability evidence after closure | restrict and delete after legal/accountability need |
| Security audit/incident logs | security investigation + defensible audit period | delete/anonymise when no longer required |
| Subscription/billing records | contract/tax/accounting requirement | retain only required finance evidence |
| Backups | rolling provider backup lifecycle | expire through provider backup policy |

## Required operational controls

- Record the final adopted periods and owner for each category.
- Prevent “keep forever” as the default.
- School termination must trigger a documented export/deletion/offboarding decision.
- Legal hold, dispute, fraud/security investigation or statutory finance retention can override ordinary deletion only for the required scope and period.
- Deletion should include primary data and queued copies; provider backups may expire on their normal protected cycle.
